# Blog App

A full-stack blog application built with Next.js, PostgreSQL and Drizzle ORM.

## Features 

- **User Authentication** – Secure sign up and login with NextAuth.js
- **Create Blogs** – Write and publish your own blog posts
- **Reading List** – Save blogs to read later
- **Like Blogs** – Show appreciation for content you enjoy
- **User Profiles** – View user information and their blogs
- **API Token** – Generate personal API tokens for external access
- **Responsive Design** – Works on all devices
- **E2E Testing** – Comprehensive Playwright test suite

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Database:** PostgreSQL
- **ORM:** Drizzle ORM
- **Authentication:** NextAuth.js
- **Styling:** Tailwind CSS
- **Testing:** Playwright
- **Language:** TypeScript

## Prerequisites

- Node.js 18+
- PostgreSQL database (Render, Neon, or local)
- npm or yarn
