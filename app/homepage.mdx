# Welcome to FSO Blog App! 

## A Full-Stack Blog Platform Built with Next.js

This application is a complete blog platform created as part of the **Full Stack Open** course. It demonstrates modern web development practices using Next.js, PostgreSQL, and Drizzle ORM.

### Features

- **User Authentication** – Sign up and log in securely
- **Create Blogs** – Write and publish your own blog posts
- **Reading List** – Save blogs to read later
- **Like Blogs** – Show appreciation for content you enjoy
- **User Profiles** – View user information and their blogs
- **Responsive Design** – Works on all devices

### Technologies Used

- **Next.js 15** – React framework with App Router
- **PostgreSQL** – Relational database
- **Drizzle ORM** – Type-safe SQL ORM
- **NextAuth.js** – Authentication
- **Tailwind CSS** – Styling
- **MDX** – Markdown with React components

###  Getting Started

1. **Sign up** for an account
2. **Create your first blog** by clicking "Create New Blog"
3. **Explore** other users' blogs
4. **Save blogs** to your reading list
5. **Like** blogs you enjoy
